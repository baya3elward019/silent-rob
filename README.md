# SILENT ROB · السطو الصامت

لعبة سطو وتسلل ثلاثية الأبعاد تعمل في المتصفح. ادخل المبنى في الظل، اسرق الجوهرة، وارجع للمخرج قبل ما الحراس يوقّعوك.

## المحتوى

- **20 مرحلة**: 5 مرسومة باليد (المعرض، البنك، المختبر، القصر، الخزنة الكبرى) و15 مبنى مولّد بغرف وممرات وخزنة بمفتاح، والمبنى بيكبر تدريجيًا.
- **5 أنواع حراس**: عادي، مدرّع (محتاج طلقتين)، سريع، أمن (مجال رؤية أوسع)، ونخبة.
- **ذكاء الحراس**: دورية، اشتباه، تحقيق في الصوت، تأهب، مطاردة، بحث في آخر مكان شافوك فيه، واكتشاف زميل نايم وتصحيته.
- **الظل**: اللمبات المطفية بتعمل مناطق ضلمة يصعب فيها اكتشافك، وتقدر تطفي النور من علبة الكهربا.
- **أنظمة الحماية**: كاميرات، ليزر بتوقيت، ليزر متقاطع، ليزر متحرك، بوابات طوارئ، وجواهر مزيفة.
- **الأدوات**: طلقة مخدّرة، ضربة صامتة من الخلف، دخان، تعطيل الأجهزة، عملة للتشتيت، الاختباء في الدواليب.
- **التقدم**: نجوم، أفضل وقت، نقاط وفلوس، و5 ترقيات، وكله بيتحفظ في المتصفح.

## التحكم

| | كمبيوتر | موبايل |
|---|---|---|
| الحركة | WASD أو الأسهم | اسحب بإصبعك في أي مكان |
| جري / تسلل | Shift / C | أزرار جري وتسلل |
| طلقة مخدّرة | Space | زر طلقة |
| تفاعل (ضربة صامتة، دولاب، نور) | E | زر تفاعل |
| دخان / تعطيل / عملة | 1 / 2 / 3 | أزرار الأدوات |
| إيقاف مؤقت / إعادة | Esc / R | زر II |

## التشغيل

افتح `index.html` في المتصفح، أو فعّل GitHub Pages من Settings → Pages واختر الفرع `main`.

اللعبة كلها في ملف واحد: Three.js r128 من CDN و JavaScript بدون أي خطوة build، والأصوات مولّدة بـ Web Audio بدون ملفات.

## تنظيم الكود داخل `index.html`

1. **DATA**: أنواع الحراس، الثيمات، المراحل اليدوية، مولّد المباني، والتحقق من قابلية الإنهاء.
2. **ENGINE**: الحفظ، الصوت، الرسم ومستويات الجودة، الشخصيات والأنيميشن، الأثاث، بناء العالم.
3. **GAME**: حالة المرحلة، ذكاء الحراس، اللاعب، الأدوات، الإنذار، والتحديث البصري.
4. **UI**: الـ HUD، القوائم، شاشة النتيجة، الإدخال، والحلقة الرئيسية.
