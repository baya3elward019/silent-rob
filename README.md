# السطو الصامت (Silent Rob)

لعبة سطو وتسلل ثلاثية الأبعاد تعمل في المتصفح. ادخل المبنى، اسرق الجوهرة، وارجع للمخرج من غير ما الحراس يوقّعوك.

- 20 مرحلة: 5 مرسومة باليد و15 مولّدة والمبنى بيكبر تدريجيًا
- حراس بمجال رؤية، كاميرات، ليزر، خزنة بمفتاح
- مسدس مخدّر، ضربة صامتة من الخلف، دخان، تعطيل أجهزة، عملة للتشتيت، جري
- يعمل على الكمبيوتر (WASD / الأسهم) والموبايل (سحب بالإصبع)

## التشغيل

افتح `index.html` في المتصفح، أو فعّل GitHub Pages من Settings → Pages واختر الفرع `main`.

مبنية بـ Three.js في ملف واحد بدون أي خطوة build.
